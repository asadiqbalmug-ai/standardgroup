# Standard Group — Project Rules

> **READ THIS BEFORE DOING ANYTHING.**

---

## 🚫 NEVER Run Locally

**Do NOT run `npm run dev`, `npm start`, or any local dev server.**

There is no localhost workflow on this project.

---

## ✅ Deployment

| Item | Value |
|------|-------|
| **Live Site** | https://standardgroup.vercel.app/ |
| **Platform** | Vercel (auto-deploy) |
| **Source** | GitHub repository |

### How to deploy changes:
1. Make code changes
2. Commit to GitHub
3. Vercel picks it up automatically and deploys

---

## 🚫 NEVER Use Netlify

This project is on **Vercel only**. Do not use `netlify.toml`, `netlify deploy`, or any Netlify tooling.

---

## 🚫 NEVER Suggest These

- `localhost:5173`
- `localhost:3000`
- `npm run dev`
- `npm run preview`
- `browser_preview` tool on localhost
- Netlify deploys

---

## Summary

> Code lives on GitHub → Vercel deploys it → https://standardgroup.vercel.app/ is the live site.
> That's the only workflow.
