## PART 1: TECHNICAL SEO FOUNDATION

### 1.1 Site Architecture Optimization
- [ ] **URL Structure**: `/category/product-name` format
  - Example: `/water-heaters/milano-80l-storage`
  - Keep URLs under 60 characters
  - Use hyphens, not underscores

- [ ] **Breadcrumb Navigation**: Implement on all product pages
  - Home > Category > Product
  - Schema markup for breadcrumbs

- [ ] **XML Sitemap**: Auto-generated, submitted to Google Search Console
  - Separate sitemaps for products, categories, pages
  - Update frequency: daily for products, weekly for categories

- [ ] **Internal Linking Strategy**:
  - Related products at bottom of each product page
  - Category links in footer
  - "Popular products" sidebar
  - Anchor text optimization (not just "click here")

### 1.2 Page Speed & Core Web Vitals
- [ ] **Target Scores**:
  - LCP (Largest Contentful Paint): < 2.5s
  - FID (First Input Delay): < 100ms
  - CLS (Cumulative Layout Shift): < 0.1

- [ ] **Image Optimization**:
  - WebP format with fallbacks
  - Lazy loading for below-fold images
  - Responsive images (srcset)
  - CDN implementation (Cloudflare/Cloudinary)

- [ ] **Code Optimization**:
  - Minify CSS/JS
  - Tree-shaking unused code
  - Critical CSS inline
  - Preload key resources

### 1.3 Mobile-First Optimization
- [ ] **Responsive Design**: Perfect mobile experience
- [ ] **Mobile Page Speed**: < 3s load time on 3G
- [ ] **Tap Targets**: Minimum 48px touch targets
- [ ] **Mobile Navigation**: Hamburger with clear categories

### 1.4 Schema Markup (Structured Data)
Implement on all pages:
- [ ] **Organization Schema**: Company info, logo, contact
- [ ] **Product Schema**: Name, description, price, availability, reviews
- [ ] **BreadcrumbList Schema**: Navigation breadcrumbs
- [ ] **LocalBusiness Schema**: Showroom locations, hours, map
- [ ] **FAQPage Schema**: For FAQ sections (improves rich snippets)
- [ ] **HowTo Schema**: Installation guides

```json
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "Milano 80L Storage Water Heater",
  "description": "Premium Italian water heater with 5-year warranty",
  "brand": { "@type": "Brand", "name": "Milano" },
  "offers": {
    "@type": "Offer",
    "price": "450.00",
    "priceCurrency": "AED",
    "availability": "https://schema.org/InStock"
  }
}
```

- [ ] **Category Campaigns**: Water heaters, Tiles, Cement, etc.
- [ ] **Competitor Campaigns**: Target competitor brand searches
- [ ] **Remarketing**: Previous visitors

- Tiles (ceramic, porcelain, marble)
- Construction Materials (cement, steel, blocks)
